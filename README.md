## 📸 PhotoClases

Aplicación web tipo galería fotográfica orientada a la visualización de imágenes organizadas por secciones o categorías. El sistema permite mostrar contenido visual de forma estructurada, aplicando principios de diseño web, organización de contenido y manejo de interfaces frontend.

Este proyecto tiene como objetivo reforzar habilidades en maquetación web, diseño visual.

### Tecnologías Utilizadas
HTML,
CSS,
JavaScript
